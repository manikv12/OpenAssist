# Deprecated Swift App

This folder contains the old native Swift implementation of OpenAssist.

It is kept for historical reference only:

- no new product work should be added here
- the main release workflow does not build it
- Build Week judges should use the React + Electron app in [`../../apps/desktop`](../../apps/desktop)

Some source files are still useful when checking older macOS behavior. Local Swift build outputs, vendored binaries, and old README screenshots are ignored by Git.
