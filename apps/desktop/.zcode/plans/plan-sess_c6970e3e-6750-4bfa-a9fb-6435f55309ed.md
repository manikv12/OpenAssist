## Goal
Make the "Recent Agent Work" experience look professional across all three surfaces: (1) the floating shelf pill, (2) the side panel that opens from it, and (3) the inline rendering of thinking / working / tool calls. Per your choice, the side panel becomes a true **edge-docked, full-height IDE-style panel** that sits beside the chat (content reserves space for it).

All changes are confined to two files: `src/App.tsx` and `src/styles.css`. CSS is additive (new classes + refined existing rules) to avoid regressing the many other places these classes are reused.

## 1. Side panel → edge-docked IDE panel (biggest change)

**Mount (`App.tsx:36682–36694`):** keep the `<AnimatePresence>` + `<motion.div>` mount at shell level, but:
- Change the motion to a right-edge slide-in: `initial {x: "100%", opacity:0}` → `animate {x:0, opacity:1}` → `exit {x:"100%", opacity:0}`, `transition {duration:0.26, ease:[0.22,1,0.36,1]}`.
- Rename wrapper class `realtime-work-drawer-motion` → `agent-work-dock-motion`.

**Dock geometry (`styles.css`):** replace the old `.realtime-work-drawer-motion` rule (`5364–5372`, fixed bottom-right) with a docked rule:
```
.agent-work-dock-motion { position:absolute; top:0; right:0; bottom:0; width:var(--agent-work-width, 380px); z-index:60; }
```
Offset parent is `.app-shell` (`position:relative`), so `right:0` = right edge of the chat column, full window height. The panel (`.realtime-work-drawer`, restyled) gets its own header.

**Content reservation (the "sits beside chat" feel):**
- Add `agent-work-open` to `shellClass` (`App.tsx:30013`, in the `cx(...)`) when `realtimeWorkDrawerOpen && realtimeWorkTaskList.length>0`.
- New CSS: `.app-shell.agent-work-open .assistant-main { padding-right: var(--agent-work-width, 380px); transition: padding-right 230ms var(--motion); }` — so chat + topbar + composer slide left to make room, animated on the same timing the shell already uses.

**Responsive (`@media max-width: 880px`):** drop the padding reservation (let the panel overlay) and cap panel width to `min(380px, 100vw−24px)` so chat isn't crushed on small windows.

**Existing `.realtime-work-drawer-motion` responsive override (`5445–5447`):** update selector to the new class.
